Privacy Policy

clip-factory · Last updated: 22 November 2026

What clip-factory is

clip-factory is a private tool used only by its operator to upload edited video clips to the operator's own YouTube channel. It uses YouTube API Services.

Data we access

When the operator authorizes clip-factory with their Google account, the tool receives permission to upload and manage videos on that one YouTube channel. The authorization token is stored only on the operator's own computer. clip-factory does not access, collect, store or share data about any other person.

Data we share

None. No data is sold, shared with third parties, or used for advertising.

YouTube and Google

clip-factory uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time from Google Account security settings.

Deleting data

Revoking access (link above) or deleting the token file on the operator's computer removes all stored authorization.
